# kodenas.dev

Source code for the [KODE NAS](https://kodenas.dev) marketing site.

Built with [Astro](https://astro.build) + Tailwind CSS. Deployed on Cloudflare.

## Pages

- `/` — KODE NAS pebble splash (coming soon)
- `/os` — KODE OS landing page

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:4321/os` in your browser.

## Build

```bash
npm run build
```
